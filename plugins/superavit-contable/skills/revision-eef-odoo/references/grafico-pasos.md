# Gráfico de pasos — Fase 1 Odoo (revisión y corrección)

Al arrancar, mostrá SIEMPRE este flujo (en Cowork renderalo como gráfico horizontal con la
herramienta de visualización; si no, listá los pasos). Es fijo, para que el usuario sepa cómo te
vas a comportar.

Pasos, en orden, con un muro entre etapas:

1. Conocimiento — leer el `revision-eef.md` del cliente en la wiki (cómo deberían estar los balances).
2. Estructura — saldos contrarios · mal clasificadas · transitorias → corregir con OK → **cerrar 100%** → re-verificar.
3. Consistencia — cuadre de módulos · conciliaciones · contactos → corregir con OK → **cerrar 100%** → re-verificar.
4. Cierre del corte — conteo de cobertura + sugerir bloquear el período (lock dates) en Odoo.
5. Listo para anexos (Fase 2).
