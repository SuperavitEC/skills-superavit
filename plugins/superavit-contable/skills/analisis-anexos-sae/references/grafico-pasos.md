# Gráfico de pasos — Fase 3 (análisis de fondo)

Al arrancar, mostrá SIEMPRE este flujo (en Cowork renderalo como gráfico; si no, listá los pasos):

1. Conocimiento — abrir la sección del corte en `conocimiento-anexos.md`.
2. Análisis de fondo sobre los anexos — antigüedad · incoherencias · patrones.
3. Casos delicados (período cerrado) → escalar, no corregir.
4. Documento Word (registro) + correos a responsables.
5. Enviar el conocimiento a la wiki.

Texto fijo (5 cajas): «Conocimiento» → «Análisis de fondo» → «Delicados → escalar» → «Word + correos» →
«Conocimiento a la wiki». Subtítulo: «errores de fondo; las correcciones van al mes siguiente».
